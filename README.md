# Advanced Web — Phase 1

Phase 1 of an advanced web course project: a static, multi-page frontend built with plain HTML, CSS and JavaScript.

## Structure

```
index.html        Entry page
main.css          Styles
renderPages.js    Page rendering logic
assets/           Images and static files
```

Later phases: [Advance-Web-Phase2](https://github.com/Osamaaaothman/Advance-Web-Phase2) (React) and [Advance-web-backend](https://github.com/Osamaaaothman/Advance-web-backend).

## Run

Open `index.html` in a browser, or serve the folder with any static server.
